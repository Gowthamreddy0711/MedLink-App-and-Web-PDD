# MedLink App and Web

This repository contains the two MedLink applications:

- `Medlink app/` - Android application and its Gradle build.
- `Medlink web/` - React/TypeScript web application and its Vite build.

## Build the Android app

```text
cd "Medlink app"
./gradlew assembleDebug
```

## Run the web app

```text
cd "Medlink web"
npm install
npm run dev
```
